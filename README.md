# Генератор четырёхзначного кода

[Открыть сервис](https://four-digit-code.onrender.com/)

Веб-сервис на Python и Flask с двумя способами получения случайного кода. В открытом режиме код обновляется кнопкой. В защищённом режиме код появляется после входа, а обновление страницы завершает доступ.

Для локального запуска установите зависимости: `pip install -r requirements.txt`. Задайте переменную окружения `APP_PASSWORD` и выполните `python app.py`. Логин по умолчанию — `test`.

# Генератор четырёхзначного кода

Один Python/Flask сервис решает оба задания:

- `/` показывает меню с выбором способа получения кода.
- `/public` показывает случайный четырёхзначный код при каждом открытии страницы. Кнопка «Обновить код» получает другой код без перезагрузки страницы.
- `/private` показывает код только после успешного входа. Разрешение на просмотр расходуется при первом показе: обновление страницы возвращает форму входа.

Код создаётся на сервере через `secrets.randbelow` и форматируется с ведущими нулями. Поэтому `0000`–`9999` — допустимые результаты. Следующий показ не повторяет предыдущий код в том же браузере.

## Запуск локально

Установите Python 3.10+ и зависимости: `pip install -r requirements.txt`.
Установите переменные `APP_PASSWORD` (пароль для входа), при желании `APP_USERNAME` (по умолчанию `demo`) и `SECRET_KEY` (длинная случайная строка). Запустите `python app.py` и откройте `http://127.0.0.1:5000/`.

## Публикация на Render

1. Загрузите этот каталог в GitHub-репозиторий.
2. В Render создайте новый Blueprint из репозитория. `render.yaml` задаёт бесплатный Python web service, команду запуска и генерирует `SECRET_KEY`.
3. При создании задайте `APP_PASSWORD` в панели Render. Пароль не сохраняется в репозитории.
4. После деплоя откройте URL вида `https://four-digit-code-demo.onrender.com/` и путь `/private`. Скопируйте фактический URL из панели Render: имя может отличаться.

Бесплатный сервис Render засыпает после 15 минут простоя; первый запрос после этого может открываться около минуты.
